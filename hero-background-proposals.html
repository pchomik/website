Hero background proposals

Four animated backgrounds for the home hero. Move the mouse over each preview. Headline and text sit above a vignette so they stay readable.

Recommended

A. Agent mesh

Nodes are agents. Glowing packets hop between them like messages or tool calls. Nodes pulse on receive. Cursor nudges nearby nodes.

B. Pipeline lanes

Parallel data lanes with comet-like events streaming left to right. Reads as CI/CD or event streaming.

C. Code stream

Falling code glyphs in columns, like a terminal or IDE. Most literal "developer" feel. Densest of the four.

D. Agent flow field

Hundreds of trajectories follow a shifting vector field and leave colored trails. Generative and calm, evokes agent paths.
